# Security policy

## Supported versions

Only the current `main` branch is evaluated for security fixes. Older commits
and unpublished development snapshots are not supported release lines.

## Reporting a vulnerability

Email security reports privately to `debusinha2009@gmail.com`. This is the
maintainer address published in the project's package metadata.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. Do not include access tokens, customer prompts, endpoint
responses, workspace identifiers, or other sensitive production data. Do not
open a public issue for an undisclosed vulnerability.
